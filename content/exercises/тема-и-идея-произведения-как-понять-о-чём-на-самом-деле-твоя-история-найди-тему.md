Возьми один из своих замыслов и заполни таблицу.

| Вопрос | Твой ответ |
| --- | --- |
| Что происходит в истории? |  |
| Чего хочет главный герой? |  |
| Почему это для него важно? |  |
| Чего он боится? |  |
| Какое убеждение определяет его поступки? |  |
| Какие последствия создаёт это убеждение? |  |
| Кто с ним не согласен и почему? |  |
| Какой вопрос возникает из конфликта? |  |
| Какое решение герой должен принять в кульминации? |  |
| Что он поймёт или изменит к финалу? |  |
| Что останется неоднозначным? |  |

Не пытайся сделать ответы красивыми. На этом этапе важнее честно разобраться в логике истории.

После заполнения таблицы сформулируй три варианта тематического вопроса.

Например:

1. Можно ли оправдать опасный поступок любовью к близкому человеку?
2. Когда надежда становится способом избежать правды?
3. Обязан ли человек отвечать за последствия выбора, сделанного из чувства вины?

Посмотри, какой вопрос лучше всего объединяет основные сцены и решения героя.

Не обязательно выбирать только один. Возможно, у истории есть центральная тема и несколько тесно связанных с ней вопросов.
