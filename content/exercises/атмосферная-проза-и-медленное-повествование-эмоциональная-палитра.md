### Упражнение: эмоциональная палитра

Перед написанием сцены выбери три характеристики атмосферы.

Например:

- уютная;
- меланхоличная;
- тревожная.

Затем подбери для каждой несколько деталей.

| Эмоция | Детали |
| --- | --- |
| Уют | Свет из окон, запах хлеба, тёплые стены |
| Меланхолия | Выцветшие вывески, пустой причал, знакомая песня |
| Тревога | Погасшие фонари, внезапная тишина, мокрые следы |

Теперь не пытайся использовать все детали сразу. Выбери те, которые естественно входят в действия героя.

Если герой идёт к другу, ему может вспомниться запах хлеба из детства. Если он замечает пустой причал, воспоминание о друге может смениться тревогой.

Так атмосфера возникает из взаимодействия внешнего мира и внутреннего состояния персонажа.
