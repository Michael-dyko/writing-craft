Выбери ближайшие три главы или три ключевые сцены. Раздели пространство истории на три кольца.

**Сцена:** места, где персонажи действуют непосредственно. Для каждого запиши один доступ, одно препятствие, одну сенсорную деталь и решение, которое там принимается.

**Зона последствий:** места, куда герои могут не попасть, но которые почувствуют результат их поступков. Для каждого укажи, какое последствие туда приходит, через какое время и кто о нём сообщает.

**Горизонт:** дальние страны, регионы и силы, о существовании которых достаточно знать. Опиши каждый элемент одной фразой через его связь с историей: «поставляет соль», «принимает беглецов», «угрожает границе».

**Ограничения:** максимум четыре элемента в каждом кольце; никаких исторических справок длиннее одного предложения; ни одного имени без функции в выбранных сценах.

После заполнения пометь сведения, которые читатель обязан узнать сейчас, и сведения, которые нужны только автору.

**Результат:** одностраничная схема глубины проработки, пригодная как план экспозиции.

**Проверка:** перескажи замысел человеку, не знакомому с миром, используя только обязательные сведения. Он должен понять, где действует герой, чего добивается и кого затронет результат. Если для ясности пришлось объяснять горизонт, ты либо рано расширил мир, либо пропустил причинную связь в зоне последствий.
