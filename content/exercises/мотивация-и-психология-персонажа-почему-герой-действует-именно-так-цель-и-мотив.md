### Упражнение 1. Цель и мотив

Выбери одного персонажа и заполни таблицу.

| Вопрос | Ответ |
| --- | --- |
| Чего герой хочет добиться? |  |
| Почему это для него важно? |  |
| Что он надеется почувствовать после достижения цели? |  |
| Чего он боится больше всего? |  |
| Что он пытается не допустить? |  |
| Как он обычно действует под давлением? |  |
| Как эта стратегия может ему навредить? |  |

Не стремись найти единственный правильный ответ. У героя может быть несколько мотивов, и не все они обязаны быть осознанными.
