## 20. Практическое упражнение: объясни мир без исторической справки

Придумай необычное правило мира.

Например:

- люди теряют воспоминания после использования магии;
- город меняет расположение улиц каждую ночь;
- в определённые дни нельзя произносить имена умерших;
- электричество работает только при солнечном свете;
- каждую лодку перед отплытием должен благословить человек, переживший туман.

Теперь напиши сцену объёмом 200–300 слов.

Условия:

1. Не используй абзац, который начинается словами «Давным-давно».
2. Не объясняй правило в виде лекции.
3. Покажи, как оно влияет на действия персонажа.
4. Дай читателю достаточно информации, чтобы понять последствия.
5. Оставь хотя бы один вопрос без ответа.

После написания проверь, может ли читатель пересказать правило своими словами.

Если не может, добавь необходимый контекст. Если может, но при этом сцена сохраняет загадочность, экспозиция, вероятно, работает.
