Выбери три предмета или явления, которые уже существуют в мире твоей истории.

Для каждого определи:

- буквальную функцию;
- связь с главным конфликтом;
- личное значение для героя;
- изменение значения по ходу сюжета;
- взаимодействие с двумя другими образами.

Затем напиши короткую сцену, в которой присутствуют все три образа, но ни один из них не объясняется напрямую.
