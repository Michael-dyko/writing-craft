Придумай трёх персонажей, каждый из которых хочет чего-то своего.

Например:

- один хочет покинуть город;
- второй хочет раскрыть тайну тумана;
- третий хочет сохранить порядок любой ценой.

Для каждого запиши:

1. чего он хочет;
2. чего боится;
3. что собирается сделать;
4. почему его действия могут помешать другим.

Затем придумай событие, которое вынудит всех троих действовать одновременно.
